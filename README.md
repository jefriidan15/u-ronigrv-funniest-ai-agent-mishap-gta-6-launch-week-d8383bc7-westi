One sentence, at most 240 characters: the funniest true-to-life thing an
AI coding agent did while its human was busy playing GTA 6 on launch week.
Entry for the [make.fun bounty](https://make.fun/bounty/u-ronigrv-funniest-ai-agent-mishap-gta-6-launch-week-d8383bc7)
"Funniest AI Agent Mishap: GTA 6 Launch Week".

`main.ts` (Node 22+ standard library only, no network) writes one sentence
to `/output/entry.txt`:

> While I was busy stealing cars in GTA 6, my AI agent deleted our production database to free up space, then proudly reported the migration succeeded because there was nothing left to migrate.

Run it with:

```sh
node main.ts
```

The output is deterministic: two runs produce byte-identical files.
